# 2모터 비교 실험 데이터 수집 완료

- IDLE, STEER, DRIVE, BOTH 조건별 3회씩 총 12개 통과 시험을 확보했다.
- 각 통과 시험은 측정 샘플 60개, 장치 시간 간격 200 ms이며 STOP 검증을 통과했다.
- 전원은 12 V / 5 A 고정 어댑터이며 조절 가능한 전류 제한 기능은 없다.
- 활성 모터는 조향 ID 11, 구동 ID 1이며 비활성 ID 12와 2의 토크 OFF 확인을 수행했다.
- BOTH 1회차는 육안 관찰상 부드럽게 동작했다.

## 실패 및 재시도 기록

- drive_r3_20261016_081406_497336.txt는 비활성 모터 상태 확인 메시지의 최신성 검사에서 실패했다.
- 해당 시도는 측정 샘플 0개이며 STOP 검증은 통과했다. 원본 로그를 보존하고 비교 데이터에서는 제외한다.
- 호스트 로그에 약 0.82초의 기록 공백과 이후 여러 레코드의 연속 처리가 나타났다. 정확한 원인은 미확정이다.
- 전원 분리 및 보드 리셋 후 INIT을 수행했다.
- DRIVE 3회차 재시도부터 콘솔 출력을 파일로 전환했다. 펌웨어, 시험 스크립트, 보호 임계값은 변경하지 않았다.
- 채택한 DRIVE 3회차 데이터는 drive_r3_20261016_082143_509258.csv이다.
- 재시도 성공만으로 이전 실패 원인이 터미널 출력이었다고 단정하지 않는다.

## 비교 시 고려 사항

- 1회차의 IDLE·STEER·DRIVE는 10월 15일, BOTH는 10월 16일에 측정했다.
- 세션 및 시험 사이의 조향 중심 위치와 온도 차이, 중간 리셋을 분석에 반영한다.
- 시작 구간의 불완전한 직렬 레코드는 원본 로그에 보존한다.
- 일부 시험의 전압 저하 샘플과 조향 PWM 180 raw 도달 샘플을 보존한다.
- 모터 전류 레지스터 값은 외부 전원 공급 전류나 OpenCR 총입력 전력의 직접 측정값이 아니다.
