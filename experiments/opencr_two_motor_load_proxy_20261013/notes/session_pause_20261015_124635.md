# 2모터 부하 대리지표 비교 실험 중간 기록

## 실험 구성

- Raspberry Pi와 OpenCR을 이용하여 연결된 모터 4개 중 1쌍만 구동한다.
- 활성 조향 모터: XM430-W350, ID 11.
- 활성 구동 모터: XM430-W210, ID 1.
- 비활성 모터: ID 12와 ID 2. 실험 중 토크 OFF 상태를 확인한다.
- 펌웨어: opencr-two-motor-telemetry-v3.
- USB 통신 속도: 115200 bps.
- DYNAMIXEL 통신 속도: 1000000 bps.
- 실행 스크립트: scripts/run_comparison_trial_v1.py.
- 각 비교 실험은 안정화 4초 후 측정 12초를 수행한다.
- 결과는 results/comparison/에 원본 로그와 측정 CSV로 저장한다.

## 완료한 검증

- 모터 탐색, 명시적 INIT 초기화, armed-IDLE 및 STOP 검증 완료.
- 하트비트 미전송 시 타임아웃으로 토크가 해제되는 동작 확인.
- 조향 단독, 구동 단독, 동시 동작의 초기 시험 완료.
- 반복 비교 실험의 1회차 IDLE, STEER, DRIVE 완료.
- BOTH 1회차 완료 여부는 아직 확인하지 않았다.

## 데이터 해석상 주의사항

- 포트 연결 직후 일부 불완전한 줄과 과거 타임스탬프가 관찰되었다.
- 해당 줄은 새로운 STATUS 응답 및 측정 시작 이전에 발생하였다.
- 원본 로그는 보존하며, 비교 분석에는 측정 구간의 CSV를 사용한다.
- 초기 출력 불연속의 정확한 원인은 아직 확인하지 않았다.
- 모터 전류 레지스터 값은 외부 전원 공급 전류의 직접 측정값이 아니다.
- 5 Hz 샘플의 최대값은 실제 순간 최대 전류를 보장하지 않는다.
- STOP의 토크 OFF 확인은 전원 차단이나 정지거리 검증을 의미하지 않는다.
- 이번 결과만으로 OpenCR 전체 전류 한계 또는 고부하 운전의 안전성을 입증할 수 없다.

## 다음 세션

1. 기존 로그와 Git 상태를 확인한다.
2. 기구 지지 상태, 바퀴의 지면 이격 및 조향 가동 범위를 확인한다.
3. 전원 및 보드 재시작 후 펌웨어와 모터 매핑을 확인한다.
4. 새 부팅 상태에서는 INIT를 1회 수행하고 성공 여부를 확인한다.
5. BOTH 1회차가 이미 저장되어 있는지 확인한다.
6. 미완료라면 BOTH --repeat 1을 실행한다.
7. 각 시험 사이에는 최소 15초간 disarmed 상태로 대기한다.
8. 동일한 기구 및 제어 설정으로 나머지 반복 시험을 수행한다.

### 예정된 반복 순서

- 1회차: IDLE → STEER → DRIVE → BOTH.
- 2회차: DRIVE → BOTH → IDLE → STEER.
- 3회차: BOTH → DRIVE → STEER → IDLE.

## 종료 상태

- 마지막으로 확인한 DRIVE 시험은 STOP 검증에 성공하였다.
- 실제 전원 분리 여부는 아래 수동 확인 항목에 별도로 기록한다.

- 수동 확인: 2026-10-15T12:46:51+09:00에 12 V 모터 전원 분리 완료.
